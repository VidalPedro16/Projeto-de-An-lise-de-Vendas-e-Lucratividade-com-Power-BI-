# Projeto de Análise de Vendas e Lucratividade com Power BI

Este projeto foi desenvolvido como parte de um desafio prático de Power BI, com o objetivo de desenvolver habilidades de criação, organização e análise de dados por meio de visualizações interativas.

O relatório utiliza uma base de dados financeiros e comerciais para apresentar informações relacionadas a vendas, unidades comercializadas, lucro, países, produtos e segmentos.

O projeto é composto por três páginas. As duas primeiras foram desenvolvidas com base em modelos apresentados durante o curso, enquanto a terceira página foi construída de forma independente, aplicando os conhecimentos adquiridos na criação de diferentes tipos de visuais.
--------------------------------------------------------------------------------------------------------------------------------------------------------------------
1. Objetivos:
   
- Desenvolver familiaridade com a interface e os recursos de visualização do Power BI;
- Criar relatórios interativos para análise de dados;
- Explorar indicadores de vendas e lucratividade;
- Representar dados geográficos por meio de mapas;
- Analisar a distribuição do lucro entre diferentes segmentos;
- Praticar a organização e apresentação de informações para facilitar a interpretação dos dados.
--------------------------------------------------------------------------------------------------------------------------------------------------------------------
2. Estrutura do relatório
Página 1 — Vendas por Produtos e Segmentos

Apresenta uma análise das vendas considerando diferentes produtos e segmentos, permitindo observar como os resultados comerciais estão distribuídos.

Página 2 — Análise de Vendas por Países e Lucro

Explora os resultados de vendas e lucratividade considerando diferentes países, proporcionando uma visão geral do desempenho comercial.

Página 3 — Análise Geográfica e de Lucratividade

Página desenvolvida de forma independente para atender ao desafio proposto, contendo:

a) Mapa 1: análise da soma de vendas e unidades vendidas por país;

b) Mapa 2: análise da soma de lucro por país;

c) Gráfico de pizza: distribuição do lucro por segmento.
--------------------------------------------------------------------------------------------------------------------------------------------------------------------
3. Tecnologias e ferramentas
   
- Microsoft Power BI

- DAX
- Visualizações interativas
- Mapas
- Gráficos de pizza
- Segmentação e filtros
--------------------------------------------------------------------------------------------------------------------------------------------------------------------

Durante o desenvolvimento do projeto, foram praticadas habilidades relacionadas à:

Criação e configuração de visuais;
Construção de relatórios no Power BI;
Análise exploratória de dados;
Utilização de campos e agregações;
Análise geográfica;
Comparação de indicadores de desempenho;

--------------------------------------------------------------------------------------------------------------------------------------------------------------------
📌 Resultado

O projeto demonstra a aplicação prática dos conceitos de Business Intelligence e Data Visualization, utilizando o Power BI para transformar dados de vendas e financeiros em informações visuais que facilitam a análise de desempenho por país, produto e segmento.

Este projeto faz parte do meu processo de desenvolvimento de habilidades em Análise de Dados e Business Intelligence, com foco no uso do Power BI para construção de relatórios e apoio à tomada de decisão.
